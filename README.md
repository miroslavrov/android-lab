# Playlist Maker

Учебное Android-приложение на Kotlin и Jetpack Compose. В этой версии доступны главный экран, настройки, вкладки медиатеки и поиск по локальному каталогу треков.

## Версии

- Android Studio — последняя стабильная (проект собран на Android Gradle Plugin 9.4.1)
- Kotlin — 2.2.10
- Android SDK Platform — 35
- Минимальная версия Android — 7.0 (API 24)
- JDK — 25

## Сборка

Нужны Android SDK Platform 35 и JDK 25 для Gradle. Минимальная версия Android — 7.0 (API 24).

Откройте проект в Android Studio и запустите конфигурацию `app` на устройстве или эмуляторе. Сборка и модульные тесты из корня проекта:

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest
```

В macOS и Linux используйте `./gradlew` вместо `gradlew.bat`. APK сохраняется в `app/build/outputs/apk/debug/app-debug.apk`.

Для проверки письма задайте `playlistMakerDeveloperEmail` с адресом разработчика в пользовательском файле `~/.gradle/gradle.properties`. Без этого параметра адресат остаётся пустым, а тема и текст письма заполняются.

## Проверка приложения

1. На главном экране откройте поиск, медиатеку и настройки. Проверьте возврат кнопкой в приложении и системной кнопкой.
2. В поиске введите `nIRVana` и нажмите лупу. После индикатора загрузки должен появиться трек «Smells Like Teen Spirit» длительностью `05:01`. Кнопка поиска на клавиатуре выполняет тот же запрос.
3. Выберите трек и очистите строку. Трек появится в истории. Проверьте кнопку «Очистить историю».
4. Введите запрос без совпадений. После загрузки появится сообщение «Ничего не нашлось».
5. Отключите Wi-Fi и мобильные данные. После нового запроса появится сообщение о проблеме со связью. Включите сеть и нажмите «Обновить». Приложение повторит запрос. Поиск использует локальные данные и эмулирует сетевой ответ с задержкой в три секунды.
6. В настройках проверьте системное меню отправки, открытие черновика письма и переход к пользовательскому соглашению.
